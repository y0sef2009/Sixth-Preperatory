# السادس الإعدادي

منصة تعليمية عربية مجانية ومنظمة لطلبة السادس الإعدادي في العراق. يوفر هذا المستودع النسخة الأولى من الواجهة الأمامية، وهي جاهزة لاستقبال المحتوى التعليمي الحقيقي لاحقًا. المشروع مستقل وغير تابع لوزارة التربية العراقية.

## التقنيات

- React
- Vite
- JavaScript
- CSS

## المرحلة الحالية

واجهة أمامية إنتاجية ومتجاوبة. لا تتضمن قاعدة بيانات أو تسجيل دخول أو محتوى تعليمي فعلي بعد، ولا تدّعي توفير ميزات خلفية غير منفذة.

## التشغيل محليًا

```bash
npm install
npm run dev
```

لبناء نسخة الإنتاج:

```bash
npm run build
npm run preview
```

## الميزات المنفذة

- واجهة عربية كاملة باتجاه RTL وتصميم متجاوب
- تنقل كامل لسطح المكتب والهاتف
- صفحات الرئيسية، المواد، وكل مادة على حدة
- واجهات الملخصات والوزاريات وبنك الأسئلة مع فلاتر ديناميكية
- واجهة إعداد الاختبارات وحالات النظام قبل توفر الأسئلة
- قسم مستقل للأسئلة والأجوبة العامة
- صفحة المصادر والبحث الشامل وحول الموقع
- حالات فراغ وغياب نتائج واضحة دون محتوى تعليمي مختلق
- بنية بيانات مركزية للمواد والفصول والمحتوى
- تطبيق ويب تقدمي PWA قابل للتثبيت مع دعم أساسي للعمل دون اتصال
- لوحة إدارة خاصة محمية بـ Supabase Auth وRow Level Security
- إضافة المحتوى ونشره كمسودة أو مادة منشورة مع رفع PDF والصور

## إضافة المحتوى

توجد بيانات المواد والفصول ومستودعات المحتوى في `src/data/content.js`. لكل مادة مصفوفة فصول مستقلة داخل `chaptersBySubject`، ولذلك يمكن إضافة فصولها أو حذفها أو إعادة ترتيبها دون التأثير في المواد الأخرى. مصفوفات المحتوى فارغة عمدًا إلى حين إضافة مواد موثوقة.

## الميزات المخطط لها

- توسيع لوحة الإدارة بتقارير وتحليلات متقدمة
- المصادقة وحسابات الطلبة والملفات الشخصية
- حفظ المحتوى وتتبع التقدم والإشعارات
- بحث فعلي واختبارات مرتبطة ببنك أسئلة موثوق
- استقبال تجارب الطلبة ومراجعتها
- مساعد تعليمي بالذكاء الاصطناعي وتحليلات الاستخدام
